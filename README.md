# Complete CI/CD Pipeline with EKS and ECR
This project focuses on pushing docker image to ECR in the `build image` stage and also pulling docker image from this same registry in the `deploy` stage instead of the DockerHub private registry used in the `complete-ci-cd-with-eks-and-ecr` git branch.
## Steps
- In AWS management console, got to ECR and create an ECR repo, named java-maven-app in my case.
- Create credentials for ECR in Jenkins: From terminal, obtain auth token using the docker push command available in ECR `java-maven-app` repo home page. create a global ecr credential in jenkins using auth token above and password AWS (username and password cred type) and configure the 2nd part of push command to use this credential in the `build stage` of pipeline.

```bash
# push command copied from ERC repo page
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin <aws_account_id>.dkr.ecr.us-east-1.amazonaws.com
# obtain password in terminal by executing first part of the command. Note that the token generated by the below command is temporary, valid for just 12 hours
aws ecr get-login-password --region us-east-1 

```
- Adjust increment version stage to use docker style naming for `IMAGE_NAME` env variable set in this stage
```bash
env.IMAGE_NAME = "<aws_account_id>.dkr.ecr.us-east-1.amazonaws.com/java-maven-app:$version-$BUILD_NUMBER"
```

- Set access and secret keys as environment variable in deploy stage
- Create a Deployment and a Service configuration for the deployment of app image pushed to ECR repo in the `build image` stage of this pipeline. The files are in `kubernetes` directory.

- Create Secret of type `docker-registry` for ECR registry from terminal with EKS cluster context as the current context
```bash
kubectl create secret docker-registry aws-registry-key \
> --docker-server=207567759818.dkr.ecr.us-east-1.amazonaws.com \
> --docker-username=AWS \
> --docker-password=<aws_ecr_auth_token>

# confirm secret creation
kubectl get secret
```
- Make use of the secret created in deployment file in spec.template.spec by adding an `imagePullSecrets` block.
```yaml
imagePullSecrets:
    - name: aws-registry-key
```
- Commit all changes to git and execute Jenkins pipeline.
