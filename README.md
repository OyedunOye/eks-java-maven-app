## Deploying to EKS Cluster from Jenkins Pipeline

This projects explores integrating deployment to EKS cluster by updating Jenkinsfile and setting up all other required configurations. The branches in this project all have a comprehensive `README.md` file which details the scenario explored.
This branch is just a simple starting point that created an empty pipeline which the other branches built on.
